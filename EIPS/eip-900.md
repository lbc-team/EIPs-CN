## Abstract

以下标准描述了一个通用的质押接口，允许轻松使用质押系统。该接口保持简单，允许实现各种用例。本标准描述了质押的通用功能，并提供有关质押的信息。

## Motivation

随着我们转向更多的代币模型，拥有一个用户熟悉的通用质押接口可能会很有用。通用接口可以被各种应用程序使用，这种通用接口可能特别有利于最近流行的代币管理注册表。

## Specification

```solidity
interface Staking {

    event Staked(address indexed user, uint256 amount, uint256 total, bytes data);
    event Unstaked(address indexed user, uint256 amount, uint256 total, bytes data);

    function stake(uint256 amount, bytes data) public;
    function stakeFor(address user, uint256 amount, bytes data) public;
    function unstake(uint256 amount, bytes data) public;
    function totalStakedFor(address addr) public view returns (uint256);
    function totalStaked() public view returns (uint256);
    function token() public view returns (address);
    function supportsHistory() public pure returns (bool);

    // optional
    function lastStakedFor(address addr) public view returns (uint256);
    function totalStakedForAt(address addr, uint256 blockNumber) public view returns (uint256);
    function totalStakedAt(uint256 blockNumber) public view returns (uint256);
}
```

### stake

质押一定数量的代币，这必须从用户那里转移给定的数量。

*data 字段可用于在更复杂的质押应用程序中添加信令信息*

必须触发 ```Staked``` 事件。

### stakeFor

质押一定数量的代币，这必须从调用者那里转移给定的数量。

*data 字段可用于在更复杂的质押应用程序中添加信令信息*

必须触发 ```Staked``` 事件。

### unstake

取消质押一定数量的代币，如果当前无法取消质押，这应该将给定数量的代币返回给用户，该函数必须恢复。

*data 字段可用于在更复杂的质押应用程序中删除信令信息*

必须触发 ```Unstaked``` 事件。

### totalStakedFor

返回地址质押的代币总数。

### totalStaked

返回质押的代币总数。

### token

质押接口使用的代币地址。

### supportsHistory

如果实现了可选的历史记录函数，则必须返回 true，否则返回 false。

### lastStakedFor

***可选：**因为并非所有质押系统都需要完整的历史记录，所以此函数是可选的。*

返回上次地址质押的区块。

### totalStakedForAt

***可选：**因为并非所有质押系统都需要完整的历史记录，所以此函数是可选的。*

返回地址在区块质押的代币总数。

### totalStakedAt

***可选：**因为并非所有质押系统都需要完整的历史记录，所以此函数是可选的。*

返回在区块质押的代币总数。

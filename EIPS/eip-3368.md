## 简述
将支付给工作量证明 (POW) 矿工的区块奖励从现有的 2 ETH 更改为 3 ETH，并启动未来两年内降至 1 ETH 区块奖励的衰减计划。

## 摘要
将区块奖励设置为 3 ETH，然后每区块略微减少，持续 4,724,000 个区块（大约 2 年），直到达到 1 ETH。

## 动机
PoW 挖矿奖励的突然下降可能导致挖矿盈利能力的突然急剧下降，这可能会驱使矿工将他们的哈希算力拍卖给出价最高者，同时他们会考虑如何处理他们现在“毫无价值”的硬件。如果同时以这种方式拍卖了足够的哈希算力，攻击者将能够以相对较低的成本（相对于奖励）在短时间内租用大量的哈希算力，并可能攻击网络。通过将区块奖励设置为 X（其中 X 足以抵消盈利能力的突然下降），然后在一段时间内将其降低到 Y（其中 Y 是低于盈利能力突然下降的数字），我们既避免了引入长期通货膨胀，同时又分散了个别矿工进入过渡范围的速度。这种方法提供了更高的信心和已发布的收益率计划，同时允许挖矿参与者有时间优雅地重新利用/出售他们的硬件。这通过保持激励与以太坊对齐，而不是强制预计短期经纪以获取最高出价，从而大大提高了以太坊的 PoW 安全性。此外，衰减促进了已知的通缩曲线时间表，与符合权益证明的总体最小可行发行指令相一致，权益证明是工作量证明的共识替代方案，为期 2 年的过渡时间表。安全在加密货币区块链中至关重要，并且对 51% 非抗性链的风险是真实存在的。以太坊当前的哈希算力范围已扩展到数十万新参与者，并且超过了原始 ATH 哈希算力/难度的 2.5 倍。虽然按哈希算力计算最大的加密货币是比特币，但以太坊在安全性方面与总网络规模相差不远。本提案的重点是保持这种安全性优势成为关键方面之一。

## 规范
调整区块、叔块和侄块的奖励
### 常量
* `TRANSITION_START_BLOCK_NUMBER: TBD`
* `TRANSITION_DURATION: 4_724_000` (大约两年)
* `TRANSITION_END_BLOCK_NUMBER: FORK_BLOCK_NUMBER + TRANSITION_DURATION`
* `STARTING_REWARD: 3_000_000_000_000_000_000`
* `ENDING_REWARD: 1_000_000_000_000_000_000`
* `REWARD_DELTA: STARTING_REWARD - ENDING_REWARD`
### 区块奖励
```py
if block.number >= TRANSITION_END_BLOCK_NUMBER:
    block_reward = ENDING_REWARD
elif block.number = TRANSITION_START_BLOCK_NUMBER:
    block_reward = STARTING_REWARD
elif block.number > TRANSITION_START_BLOCK_NUMBER:
    block_reward = STARTING_REWARD - REWARD_DELTA * TRANSITION_DURATION / (block.number - TRANSITION_START_BLOCK_NUMBER)
```

## 理由
之所以选择 2 年，是因为它使矿工有足够的时间找到其硬件的替代用途，和/或将其硬件重新投放市场（例如，以游戏 GPU 的形式），而不会突然涌入市场。本提案应仅被视为万不得已的手段，作为我们手中的王牌，以应对“网络需要快速吸引哈希算力，然后随着时间的推移逐渐释放”的情况，而不是“计划包含在 X 硬分叉中”的情况；建议使其处于快速通道状态，但除非需要，否则不要部署到主网。

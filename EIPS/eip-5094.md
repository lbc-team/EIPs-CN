## 摘要

本标准包含了通过 URL 将网络添加到钱包所需的所有信息，包括 `chainId`、`rpc_url`、`chain_name` 等参数，以便通过 URL 本身提供网络配置。

## 动机

正如在使用 [EIP-681](./eip-681.md) 及其在当前移动钱包中的实现时所观察到的，交易可以进行、批准、查看和使用。但是，如果钱包被指示在尚未配置过的链上执行交易，则操作往往会失败。

这是可以理解的，因为提供的 `chain_id` 仅构成连接到网络所需内容的一部分。本 EIP 旨在引入一种新型 URL，用于深度链接、QR 等，以允许用户无缝地将新网络添加到他们的（例如移动）钱包中，从而能够更轻松地参与 `pay-`、`tx-` 或其他以太坊 URL 交互。

作为 [EIP-831](./eip-831.md) 及其相邻的 [EIP-681](./eip-681.md) 和 [EIP-2400](./eip-2400.md) 的扩展，本文档旨在标准化通过 URL 添加新网络和切换网络。在这种情况下，用户便利性是首要的。

引入此 EIP 旨在桥接到将在不久的将来引入的更安全的 RPC 列表系统。

## 规范

### 语法

网络切换 URL 在其 schema（协议）部分包含“ethereum”，其构造如下：

    network_add             = erc831_part "add" "@" chain_id [ "/" ] "?" parameters
    erc831_part             = "ethereum:network-"
    chain_id                = 1*DIGIT
    parameters              = parameter *( "&" parameter )
    parameter               = key "=" value
    key                     = required_keys / optional_keys
    required_keys           = "rpc_url" / "chain_name"
    optional_keys           = "name" / "symbol" / "decimals" / "explorer_url" / "icon_url"
    value                   = STRING / number
    number                  = 1*DIGIT

`STRING` 是任意长度的 URL 编码的 Unicode 字符串，其中分隔符和百分号 (`%`) 必须使用 `%` 前缀进行十六进制编码。

如果参数中的 *key* 是 `decimals`，则 *value* 必须是 `number`。

### 语义

`chain_id` 是强制性的，表示十进制链 ID，这样我们就有了要添加的网络的标识符。

`rpc_url` 表示为 RPC URL 的数组。必须至少存在 1 个 `rpc_url`，格式为 `rpc_url=https%3A%2F%2Fpolygon-rpc.com`，或者当存在多个时，格式为 `rpc_url=https%3A%2F%2Fpolygon-rpc.com&rpc_url=https%3A%2F%2Frpc-mainnet.matic.network`。

`chain_name` 是指定要添加的网络名称所必需的。

如果提供 `name` 和 `symbol`，则应为表示原生代币的可读字符串。

如果提供 `decimals`，则必须是一个非负整数，表示原生代币的小数精度。

如果提供 `explorer_url`，则必须指定一个或多个指向该链的区块浏览器网站的 URL。

如果提供 `icon_url`，则必须指定一个或多个指向合理大小的图像的 URL，这些图像可用于直观地识别该链。

添加具有 RPC 端点 `https://rpc-polygon.com` 和 `https://rpc-mainnet.matic.network`、名称 `Polygon Mainnet`、代币 `Matic`、符号 `MATIC`、小数 `18`、浏览器位于 `https://polygonscan.com/` 和链 ID `137` 的网络的示例如下所示：

```URL
ethereum:network-add@137/?chain_name=Polygon%20Mainnet&rpc_url=https%3A%2F%2Frpc-polygon.com&rpc_url=https%3A%2F%2Frpc-mainnet.matic.network&name=Matic&symbol=MATIC&decimals=18&explorer_url=https%3A%2F%2Fpolygonscan.com
```

## 理由

为了进一步推进以太坊 URL 的发展，网络配置是以太坊 URL 可能性的必要补充。这将提高 URL 的功能，并为非主网用户提供一种无需手动配置钱包即可连接的方式。

该 URL 遵循 [EIP-831](./eip-831.md)，其中 `PREFIX` 为 `network`，`PAYLOAD` 为 `add` 和类似于 [EIP-681](./eip-681.md) 的 `chain_id` 和参数的组合。

选择 `PREFIX` 为 `network` 是为了允许进一步扩展并允许遵循 `network-x` 模式的变体。

用于添加 Optimism 网络的示例 URL

```URL
ethereum:network-add@10/?chain_name=Optimistic%20Ethereum
&rpc_url=https%3A%2F%2Fmainnet.optimism.io&name=Ethereum&symbol=ETH&decimals=18&explorer_url=https%3A%2F%2Foptimistic.etherscan.io
```

该规范允许指定多个 `rpc_url` 和 `explorer_url`。这样做是为了与 [EIP-681](./eip-681.md) 中提到的 `TYPE` 的解析重叠。

## 安全考虑

URL 可能会被恶意构造以欺骗用户。用户在使用任何链接之前应该确认 URL 的来源。以及在确认任何交易之前检查来源和交易详细信息。应用程序应该在添加网络之前显示网络配置，以便用户可以确认要添加的网络配置的有效性。
